# Ruang Kopi

Game dekor dan bisnis kedai kopi bergaya pixel isometrik. Dibuat dengan HTML + Canvas, tanpa library dan tanpa gambar eksternal (semua sprite digambar dari kode).

- **Mode Santai**: dekor bebas, semua item gratis.
- **Mode Bisnis**: layani pelanggan, kumpulin uang, beli dekor dan mesin baru.

Progres disimpan di browser (localStorage). Buka `index.html` langsung atau lewat GitHub Pages.
